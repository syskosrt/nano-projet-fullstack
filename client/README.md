# Nano Projet

Front React pret a l'emploi avec Vite. Il consomme l'API du dossier voisin `nano-projet-api`.

## Demarrer

```bash
npm install
npm run dev
```

Par defaut, le front appelle `http://localhost:3001/api`.

## Scripts

- `npm run dev` lance le serveur de developpement.
- `npm run build` cree la version de production.
- `npm run preview` sert la version de production en local.
- `npm run lint` analyse le code avec ESLint.
